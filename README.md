# ilefoastro-digital-vault

A public sandbox with a sample record structure for the Ilefoastro Digital Vault, the heritage project of Temitope Israel Balogun.

> All records here are sample data. Do not commit real family data to this repository.

## What is in this repository

- `sample_schema.md`: the fields used in a sample lineage record, with example values.

## About the Ilefoastro Method

The Method is a three-step approach to preserving Yoruba family lineage: oral ethnography, archival checking, and ancestral visual brand heraldry. See the [Ilefoastro-Method repository](https://github.com/ilefoastro/Ilefoastro-Method).
